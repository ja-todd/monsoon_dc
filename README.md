# monsoon_dc
## Diurnal cycle of monsoon systems in km-scale simulations run by the Met Office (horizontal resolution in brackets): 
### -  GAL9 - conventional mass-flux parameterization (Willett et al., 2025) [10 km].
### -  CoMA9 - new `semi' scale-aware scheme (Whitall et al., 2022) [10 km, 5 km]
### - RAL3(.3) - no convection parameterization (Bush et al., 2025) [5 km]
